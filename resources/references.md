# References

The first four are the most useful during the required project. The others are optional if you want to understand the wider ideas. The descriptions below refer to the linked pages, not to material students must memorize.

| Resource | Type | What it teaches and why it fits | Use |
| --- | --- | --- | --- |
| [Creating arrays in your programs](https://dev.java/learn/language/constructs/basics/arrays/) | Official Java lesson | Array creation and indexing; useful for the three move counts | Recommended |
| [Control flow statements](https://dev.java/learn/language/constructs/basics/controlling-flow/) | Official Java lesson | `if` and loops used to find the highest count | Recommended |
| [Random, Java 17](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Random.html) | Official API reference | `nextInt(3)` and its range; explains random fallback | Recommended |
| [Scanner, Java 17](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/Scanner.html) | Official API reference | Reading menu input with `nextLine()` | Recommended |
| [Frequency and relative frequency](https://openstax.org/books/introductory-statistics-2e/pages/1-3-frequency-frequency-tables-and-levels-of-measurement) | OpenStax textbook | Distinguishes counts from proportions; useful if discussing how often a move appears | Optional |
| [Rock Paper Scissors algorithms](https://daniel.lawrence.lu/dllu2/rps.html) | Strategy guide by Daniel Lawrence | Includes frequency counting, recency weighting, rotations, and history matching; compare with this bot | Optional |
| [Moving average](https://en.wikipedia.org/wiki/Moving_average) | Encyclopedia overview | Introduces fixed windows over recent observations; the optional sliding-window challenge uses the same idea of a recent window, but counts categories rather than averages | Optional |
| [The Rock-Paper-Scissors Game](https://arxiv.org/abs/1903.05991) | Research review | Introduces game theory and mixed strategies through this game; further reading only | Optional |
| [Social cycling and conditional responses](https://pubmed.ncbi.nlm.nih.gov/25060115/) | Research paper abstract | Studies how people's moves depend on previous outcomes; shows why simple overall frequencies can miss behavior | Optional |
| [Repeated play and adaptive behavior](https://pubmed.ncbi.nlm.nih.gov/38657419/) | Research paper abstract | Studies repeated human play against adaptive opponents; context for sequence prediction | Optional |

The links were checked for reachable pages and matching descriptions while preparing this repository. Research papers and game theory are outside the required work.
